Ícones do Projeto Abundância

93 pictogramas distintos da biblioteca Lucide Static, versão 1.71.0, foram associados aos 118 itens do inventário. O conjunto inclui mais um SVG genérico de fallback para itens que venham a ser adicionados no futuro (94 arquivos SVG no total).

Fonte oficial: https://lucide.dev/
Repositório oficial: https://github.com/lucide-icons/lucide
Licença: ISC. O texto integral está em LICENSE.txt.

Os ícones são decorativos; os nomes dos itens continuam como texto acessível na interface. Os dados do inventário não foram alterados.
