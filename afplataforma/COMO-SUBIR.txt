COMO SUBIR ESTA PASTA NO GITHUB
================================

1. Abra a pasta afplataforma DESTE zip (não a pasta pai).
2. GitHub: AKASHAHUB → repositório / pasta afplataforma
3. Substitua / envie:

   index.html
   complementar/
   CAMADAS.txt
   COMO-SUBIR.txt
   assets/css/main.css
   assets/js/  (incluindo covers.js)
   assets/img/treino/  (7 máquinas + 7 halteres)
   assets/img/capas/
   assets/img/loja/
   assets/img/auth/
   assets/img/mentor/yan.jpg

NÃO apague firebase/, data/, nem os outros JS.
NÃO envie assets/img/_hold_sensual

Se o site abrir como pasta/pasta:
deixe só akashahub.com.br/afplataforma/index.html

TROCAR IMAGENS (só mentor logado):
Toque em TROCAR na capa. A foto fica neste aparelho.
Para ficar permanente: baixe a foto e substitua o arquivo em assets/img/.

MATERIAIS PDF (mentorando):
Pasta assets/materials/ — 21 PDFs dos módulos + constelação + dicionário + livros/.
O mentorando abre pelo botão “Abrir material” (viewer na plataforma + tela cheia).
NÃO coloque roteiro de call nesta pasta. Roteiro = Firestore afMentorScripts.

VÍDEOS DE YOGA / TREINO:
No cartão da série, o mentor cola URL YouTube ou Cloudinary e toca Salvar.
Fica neste aparelho. Para todos os alunos: cole a regra afMedia em RULES-AF-ACCESS.txt.

QUITEI:
Ferramenta nativa (menu Quitei, abaixo de Complementar).
Dados em afTools/{uid}/tools/quitei — mesma regra das outras ferramentas.
Não usa o Firebase quitei777.
